# Прямой перенос нефтедобычи

DAG `oil_layered_migration`, одна task `migrate_and_validate`. INITIAL: `{"mode":"initial"}`. REFRESH: `{"mode":"refresh","overlap_offsets":10}`. Автоматического расписания и retries нет; одновременно допускается один run.

Один процесс сохраняет native GP read-only transaction для всех двадцати объектов и расчётов. Внутри task соблюдается топологический порядок: родитель должен пройти VALIDATED до ребёнка. INITIAL выполняет 14 прямых копирований через Python/Cedrus и 6 Spark-расчётов, 65 quality gates. REFRESH строит отдельный `_next` из INITIAL/raw, 58 gates. Новые технические batch IDs создаются вместе с родителями batch_control; бизнес-ключи сохраняются.

Граница C0/C1 выбирается внутри run без ожидания пустой очереди. Предварительный экспорт и отдельный snapshot-DAG не нужны. При ошибке подтверждённые записи кандидата компенсируются в обратном порядке; неизвестный исход или чужие изменения требуют сверки. READY не переключает Superset автоматически.

`runtime.airflowignore` разворачивается как `managed/.airflowignore`: исключает вспомогательные Python-модули из поиска DAG, сохраняя импорт этих модулей из основного DAG-файла.
