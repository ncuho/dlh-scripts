# Нефтегазовая миграция Greenplum → Lakehouse

Первая волна «Добыча по месторождениям» 21 ноября 2026 загружена и рассчитана в Iceberg через CedrusData Engine на остановленной границе источника. Все 14 объектов, включённых в сверку, совпали с GP по полному мультимножеству строк; доказательство — `quality/wave1-reconciliation.json`.

Вторая волна «Эффективность добычи и простои» остаётся в Greenplum для будущей демонстрации. Динамическая синхронизация, перенос дельты и переключение BI для неё не выполнены. Отдельные коммиты таблиц Iceberg не образуют общей транзакции.

`sql/wave1-sql-plan.json` содержит фактически выполненные через Cedrus DDL/CTAS и расчёты. `dlh/` — проект Spark-перерасчёта и альтернативный план переноса: он пока не проверен на целевом Spark runtime. `quality/` — результаты и шаблоны сверки; `docs/` — модель и план показов. Данные синтетические, масса нефти в тоннах, временная зона UTC. Секретов в репозитории нет.
