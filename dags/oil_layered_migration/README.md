# Перенос трёх слоёв

24 задачи: preflight, 20 объектных операций, общая сверка, компенсация и READY. Config содержит mode и source_lock из открытой административной GP-транзакции; REFRESH допускает overlap_offsets. Без действительных SHARE-lock всех исходных таблиц загрузка запрещена. Оператор держит транзакцию до завершения сверок, затем снимает блокировки и возобновляет исходный ingestion.
