# source_fence

Удерживает живую границу на время build: lease Kafka, запрет producer write, pause GP sink и GP advisory lock. При потере подтверждения прекращает работу.

Исходный код: [source_fence.py](source_fence.py).

## Статус сущности

- **GitHub:** код и описание находятся в этой папке.
- **Data Catalog:** Отдельной карточки вспомогательного runtime нет; назначение отражено DAG/описанием интеграции.
- **Lakehouse:** Механизм установлен; не является переносимой бизнес-таблицей.
