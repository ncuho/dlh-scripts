# Учётная запись публикации

Роль `OilMigrationPublisher` позволяет штатной сервисной учётной записи создавать и изменять принадлежащие ей отчёты, графики и datasets на Cedrus database 2. Доступ к исходному GP database и административные права не выдаются. Запускать внутри web-контейнера Superset; пароль берётся существующей runtime-конфигурацией, в коде его нет.
