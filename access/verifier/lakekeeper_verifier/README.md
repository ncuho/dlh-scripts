# lakekeeper_verifier

Read-only сервис проверки актуальных snapshots, table-level grants и отсутствия избыточного родительского доступа перед публикацией.

Исходный код: [lakekeeper_verifier.py](lakekeeper_verifier.py).

## Статус сущности

- **GitHub:** код и описание находятся в этой папке.
- **Data Catalog:** Отдельной карточки вспомогательного runtime нет; назначение отражено DAG/описанием интеграции.
- **Lakehouse:** Механизм установлен; не является переносимой бизнес-таблицей.
