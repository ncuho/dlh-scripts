# Развёртывание расчётов

`python3 deploy_release.py` загружает проверенный DAG и библиотеки в настроенный S3-префикс Airflow `DAGs/managed/`. Учётные данные используются внутри существующего sidecar; старый файл этого DAG удаляется после проверки новых объектов. Бизнес-таблицы и данные не создаются.
