# Контроль качества и сверка

`gates(schema, chain)` проверяет контракт событий, версии, SCD2 и покрытие фактов. `comparisons(schema, chain)` сравнивает полную историю и бизнес-таблицы через двусторонний EXCEPT ALL на одной удерживаемой границе. Каждый результат должен быть равен нулю. Production не обращается к downtime-таблицам.
