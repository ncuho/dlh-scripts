# Lakehouse: проект миграции цепочки продаж

В `commerce-demo/dlh` лежат проект DDL Iceberg и Spark-расчёт, в `quality` — шаблоны сверки, в `SCENARIO.md` — сценарий вебинара. Это подготовленные артефакты: целевые таблицы, ingestion, сверка и полный перенос не подтверждены работающими; миграция не запускалась.

Spark-скрипт по умолчанию не пишет данные; режим подготовки выпуска создаёт пять отдельных таблиц и манифест, как описано в `dlh/RELEASE.md`. Несколько коммитов не являются единой транзакцией; этот режим ещё не проверен на стенде. До показа нужны согласованные снимки источника, проверка прав и коннекторов, обработка дельты и сквозная сверка.
