# Наблюдение Kafka → DLH

Пять read-only SELECT для Cedrus/Trino: число и последние offsets raw, разница между полученными/применёнными позициями, последние документы, применённые версии Silver и сумма отчёта Gold. Выполняйте по одному, повторяйте при работающем producer. Первое поступление raw начинается после запуска Iceberg Kafka sink; Gold меняется только после принятой Spark-обработки. Ненулевой хвост между запусками нормален, а нулевой хвост не заменяет DQ-сверку на согласованной границе.
