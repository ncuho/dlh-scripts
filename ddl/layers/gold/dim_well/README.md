# gold.dim_well

Историческое измерение скважины, её принадлежности месторождению и статуса. Версия выбирается на производственную дату.

`dim_well.sql` создаёт пустую INITIAL-таблицу; `refresh.sql` — отдельного кандидата `_next`. Загрузку и проверку выполняет task `oil_mart__dim_well` DAG `oil_layered_migration`. После частичного сбоя не повторяйте INSERT без сверки receipt.
