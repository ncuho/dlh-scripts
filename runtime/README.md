# Исполнитель ограниченной волны

Каталог содержит файлы целевого контура для ограниченного запуска из Airflow. Копия исходников зафиксирована на момент подготовки; фактический исполняемый набор и его хеши проверяются отдельно перед развёртыванием.

| Файл | Назначение |
|---|---|
| `airflow_oil_wave2.py` | DAG без автоматического расписания: действия build, catalog_ready, publish и catalog_published; режим build поддерживает initial/refresh. |
| `bounded_delta.py` | Проверка манифеста, входных снимков и диапазонов. |
| `cedrus_release_runner.py` | Формирование изолированного выпуска и проверка результатов через Cedrus. |
| `sql_plan.py`, `dq_sql.py` | SQL-план преобразований и проверки качества. |
| `source_fence.py`, `fence_controller.py`, `fence_probe_socket.py` | Удержание и проверка согласованной границы источника и Kafka. |
| `publish_dataset.py`, `superset_auth.py` | Проверяемая публикация набора Superset и аутентификация. |
| `runtime_catalog.py` | Регистрация и обновление состояния выпуска в каталоге. |
| `grant_serving.py` | Отдельная административная утилита: выдаёт права, в работающий набор Airflow не загружена и не выполнялась в рамках верификации. Права подтверждаются пользователем штатными средствами. |

GP checkpoint, границы всех Kafka partitions, topic ID, исходный snapshot и удерживаемая граница должны быть согласованы в одном прогоне. Отдельные коммиты Iceberg не образуют общей транзакции: нужен проверяемый механизм публикации связанного набора. Ни локальные tests, ни наличие этих файлов не доказывают успешный живой перенос или постоянную синхронизацию. Настройки, токены, lease и сертификаты передаются штатными защищёнными средствами и сюда не записываются.
