# project_spark

Spark Connect транспорт с отдельным Jupyter kernel каждого запуска.

В рабочем Bridge библиотека разворачивается с immutable spec в S3 Airflow. Она не содержит паролей и не выполняет перенос при импорте. Экземпляр проекта задаёт namespaces, объекты, SQL, границу и проверки. Производственный исходный код находится в Platform Bridge; при обновлении копии сверяйте SHA-256 файлов.
