# catalog_launcher_overlay

Расширяет MCP каталога узкими операциями удаления BI-lineage и обновления описаний разрешённых BI-объектов.

Исходный код: [catalog_launcher_overlay.py](catalog_launcher_overlay.py).

Операция описания BI проверяет не только UUID, но и разрешённый FQN панели/четырёх графиков. Поэтому повторная регистрация карточки с новым UUID не требует расширять область разрешённых объектов.

## Статус сущности

- **GitHub:** код и описание находятся в этой папке.
- **Data Catalog:** Это код обслуживания каталога; отдельная бизнес-карточка Python-модуля не создаётся.
- **Lakehouse:** Runtime registration и MCP overlay установлены; обслуживают целевой выпуск и BI lineage.
