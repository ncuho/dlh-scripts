# Проверки объекта

Каждый SQL возвращает одно число `n`: ноль означает успех. Фаза INITIAL/REFRESH/both задаётся исполняемым планом `pipelines/oil_layered_migration/oil_layered_plan.py`. Проверки выполняются сразу после загрузки этой таблицы, до допуска дочерних задач. Это код контроля данных, не сохранённый результат сверки.
