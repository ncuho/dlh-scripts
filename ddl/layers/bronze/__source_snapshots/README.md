# Исторический вход миграции

Одна техническая Iceberg-таблица содержит экспорт двадцати исходных объектов одного GP snapshot. `export_id` разделяет запуски C0/C1, `object_symbol` определяет исходный объект, `row_no` задаёт координату строки внутри экспорта, `row_json` сохраняет значения в порядке утверждённых колонок.

Это транспортный вход и эталон сверки, а не дополнительная бизнес-модель и не CDC. Native read-only загрузчик читает GP в REPEATABLE READ, проверяет SHA-256 каждого блока и закрепляет Iceberg snapshot. Целевые SQL/Spark запросы типизируют значения по утверждённой схеме. Ingestion и расчёты GP не приостанавливаются. Схема или таблицы-копии внутри GP не создаются.

Файлы данных Parquet обслуживаются Iceberg/LakeKeeper на S3. Экспорты сохраняются до завершения приёмки и периода аудита. Нельзя удалять их данные или истекать закреплённые snapshots, пока нужны повторяемые проверки. Незавершённый экспорт не допускается к загрузке бизнес-слоёв.
