# Физические слои Lakehouse

`bronze` принимает Kafka landing и шесть Stage-объектов, `silver` хранит девять объектов Data Vault, `gold` содержит пять объектов размерной модели и отчёта добычи. В каждой папке сущности находятся DDL и описание.

Основной SQL создаёт INITIAL с исходными именами; `refresh.sql` создаёт отдельный кандидат `_next`. Создание таблиц не переносит данные. Загрузку, порядок зависимостей и проверку ключей выполняет DAG `oil_layered_migration` через Cedrus и Spark. Публикация отчёта разрешена только после READY.

Iceberg не исполняет GP PK/FK, distribution или индексы: уникальность, ссылки и SCD2 проверяются явными запросами. Все принятые таблицы и raw сохраняются во время построения следующего кандидата.
